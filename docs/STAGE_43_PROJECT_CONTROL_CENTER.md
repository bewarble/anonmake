# Stage 43 — Центр управления проектами

Главная страница проектов показывает аудиторию, активные VIP-статусы, выручку
за день, 7 и 30 дней, очереди, ошибки, рассылки и состояние Impaya.

Для каждого проекта доступна отдельная карточка с быстрыми переходами,
последними заданиями доставки, платежами и настройками операционного статуса.
Администратор проекта видит только назначенные ему проекты. Изменение названия,
отключение и режим обслуживания доступны только суперадминистратору.
