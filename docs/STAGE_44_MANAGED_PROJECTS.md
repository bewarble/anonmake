# Stage 44 — Управляемые проекты

Проекты создаются из админ-панели, токены проверяются через Telegram и хранятся зашифрованно. Сервис `managed-bots` автоматически запускает polling для проектов с режимом `managed`. Существующие четыре проекта сохраняют режим `external` и продолжают работать в отдельных контейнерах.
