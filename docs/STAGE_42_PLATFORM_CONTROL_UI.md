# Stage 42 — Центр управления платформой и обновление интерфейса

Этап обновляет страницы управления администраторами и платёжными настройками:

- единый адаптивный дизайн форм и карточек;
- русские подписи пользовательского интерфейса;
- редактирование аккаунтов, ролей, паролей, статуса и доступных проектов;
- безопасное удаление аккаунтов;
- запрет удаления собственного аккаунта и последнего активного суперадминистратора;
- отдельные визуальные карточки Impaya для каждого проекта.

Технические коды и имена полей базы данных не переименовываются.
